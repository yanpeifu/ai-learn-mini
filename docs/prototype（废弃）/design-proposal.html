「漫画课桌」风格提案

界面是一本摊开的《漫画Party》,摊在温暖的书桌上 —— 治愈打底 · 漫画点缀

基调遵守 PRD 3.12:轻松但有成就感,不亢奋 | 对应《产品需求文档》v1.1 · 2026-09-15

1

设计理念 · 三根支柱

从《漫画阿衰》提炼"漫画精神",从治愈系提炼"情绪温度",从 PRD 提炼"反馈即灵魂"。

🎨漫画精神(点缀)

亮黄封面底 + 红色粗描边标题的撞色记忆;粗黑描边贴纸卡片;拟声词(「叮!」「唔…」)只在反馈瞬间出现;夸张但克制的表情语言。

来自:阿衰封面黄底红字 / 漫画符号语言

🧸治愈打底(基底)

奶油黄纸面 + 网点纹理;文字用深咖灰不用纯黑;大圆角、大留白;答错用温和的桃粉气泡而不是刺眼大红 —— 挫败感被"接住"。

来自:PRD 答错反馈要求 / 多邻国"不用纯黑"经验

⚡反馈即灵魂(交互)

答题的 200ms 反馈决定复玩意愿:答对绿色扩散 + 星星迸溅;连击弹速度线贴纸;AI 讲解做成颜宝老师的对话气泡 —— 像漫画角色在跟你说话。

来自:PRD 3.12 L11 微交互设计

吉祥物「颜宝 YANBAO」· 自创 IP

一颗圆滚滚的小墨滴,头顶两根呆毛,戴圆眼镜 —— 造型治愈圆润,表情夸张多变(承接阿衰的表情语言),SVG 绘制,零版权风险。

答对啦!得意颜宝

答题页答对瞬间出场:弯月眼 + 张嘴大笑,配「叮!」星星贴纸。对应 PRD 答对反馈。

唔…让我想想思考颜宝

生成大纲/出题时出场:O 型嘴 + 头顶问号,配骨架屏循环文案("正在理解你的内容…")。

没关系,再想想鼓励颜宝

答错瞬间出场:闭眼温柔微笑 + 头顶小爱心,配桃粉「唔…」气泡 —— 温和不挫败。

为什么不是高仿阿衰? 阿衰是猫小乐的版权 IP,直接使用会在产品化时构成侵权。 颜宝保留其精神内核 —— 夸张的表情语言、黄黑描边、贴纸感,但形体是原创的; 三个表情对应答题页的三种反馈状态,后续可扩展(睡觉=无进度、举旗=通关、戴状元帽=三星)。

原型文件规划 · 一行三列 / 响应式

核心业务流程与扩展功能分开成文件;每屏为 375 手机框,CSS Grid 一行三列,窄屏自动折行。

📄 入口导航

prototype/index.html
  • 全部页面的索引目录,点击跳转到对应原型
  • 内嵌精简版设计规范(色板/字号/间距/组件)
  • 页面跳转关系图(对应 PRD 5.5)

🧩 核心业务流程

prototype/core-flow.html
  • P1 首页(空态 / 有继续学习态)×2
  • P2 大纲确认(生成中 / 可编辑 / 生成失败)×3
  • P3 答题(单选 / 多选 / 判断 / 答对 / 答错 / 连击)×6
  • P4 结算(三星 / 低分薄弱) ×2
  • P5 我的(有记录 / 空状态)×2
  • 中途退出确认弹窗 / 题目举报入口×2

🚀 扩展功能(V0.5+)

prototype/extended.html
  • 关卡地图(SVG 蜿蜒路径 · 四种节点状态)
  • 错题本 + 一键重练
  • 今日复习(间隔重复入口卡片)
  • 复盘报告(雷达图 + 趋势折线 + 错误模式)
  • 分享海报(成果型 / 挑战型)×2
  • 扫码挑战答题入口页
