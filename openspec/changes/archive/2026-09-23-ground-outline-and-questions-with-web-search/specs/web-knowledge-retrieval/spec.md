# Spec Delta

## Purpose

为学习内容提供外部知识来源：既能按关键词检索公开网页，也能按用户给出的网址抽取整页正文，
并按知识特征动态调整检索策略，使系统在模型自身记忆不可靠时仍有可依据的资料。

## ADDED Requirements

### Requirement: 按关键词检索外部资料

当学习内容需要外部依据时，系统 SHALL 能够用一组关键词检索公开网页，
并得到带来源网址（URL）与内容片段的检索结果。

#### Scenario: 文字输入需要外部资料

- **WHEN** 用户提交一段文字内容，且系统判断该内容需要最新或更可靠的外部资料
- **THEN** 系统返回一组检索结果，每条结果至少包含标题、来源网址与内容片段

#### Scenario: 检索没有命中结果

- **WHEN** 关键词检索未返回任何结果
- **THEN** 系统视为「本次没有可用资料」并继续后续流程，不得因此中断生成

### Requirement: 按网址抽取整页正文

当用户输入中包含网址时，系统 SHALL 抽取该网址对应页面的正文作为知识源。

#### Scenario: 输入是单个网址

- **WHEN** 用户提交的内容是一个网址
- **THEN** 系统抽取该页面的正文，并以该正文作为后续生成知识源

#### Scenario: 输入同时包含网址与说明文字

- **WHEN** 用户提交的内容里既有网址，也有自己补充的说明文字
- **THEN** 系统以该网址抽取出的正文为主要知识源，并保留用户的说明文字作为补充信息

#### Scenario: 网址无法抽取

- **WHEN** 网址抽取失败（页面不可访问、被拒绝、超时或返回错误状态）
- **THEN** 系统向用户明确提示该链接无法读取、建议改用粘贴文字或更换链接
- **AND** 系统不得在没有任何正文的情况下继续生成题目

### Requirement: 网址输入不受文字字数规则约束

通过网址获得的知识源 SHALL NOT 受文字输入的字数校验约束。

#### Scenario: 抽取出的正文远超文字输入上限

- **WHEN** 网址抽取出的正文长度超过文字输入的字数上限（2000 字）
- **THEN** 系统仍然接受该知识源并继续生成，不得以「内容太长」为由拒绝

#### Scenario: 抽取出的正文很短

- **WHEN** 网址抽取出的正文长度低于文字输入的字数下限（20 字）
- **THEN** 系统不套用该下限，是否继续由后续流程按其自身规则决定

### Requirement: 依据知识特征动态选择检索参数

系统 SHALL 依据知识复杂度、时效性与用户所在地区，动态选择检索的深度、结果条数与地域/语言偏置，
且 MUST 保证所有对外可见行为不受参数选择方式影响。

#### Scenario: 简单且稳定的知识

- **WHEN** 待检索的是教科书式的常见概念
- **THEN** 系统采用较浅的检索深度、较少的结果条数与较短的内容片段，以控制延迟与用量

#### Scenario: 很新或复杂的知识

- **WHEN** 待检索的是一门新出现的技术、工具或概念
- **THEN** 系统采用更深的检索深度与更多的结果条数，并在结果中获取更完整的页面内容

#### Scenario: 强时效性内容

- **WHEN** 待检索内容与近期发生的事件或刚发布的版本相关
- **THEN** 系统对检索结果施加时间范围限制，优先返回近期资料

#### Scenario: 面向国内用户

- **WHEN** 用户输入为中文，或用户所处地区为国内
- **THEN** 系统对检索结果施加中文/地域偏置，优先返回中文与国内来源

#### Scenario: 面向国外用户

- **WHEN** 用户输入为英文，或用户所处地区为国外
- **THEN** 系统不施加中文/国内偏置，按英文与全球来源检索

### Requirement: 检索不可用时降级且不阻断生成

当关键词检索因为缺少凭证、网络不可达、限流或超时而无法完成时，
系统 SHALL 跳过本次检索并继续完成生成，MUST NOT 因此向用户抛出错误。

#### Scenario: 未配置检索凭证

- **WHEN** 部署环境没有配置检索所需的 API Key
- **THEN** 系统完全不发起检索，按原有流程完成生成

#### Scenario: 检索服务限流或超时

- **WHEN** 检索请求返回限流或超时错误
- **THEN** 系统跳过本次检索、继续生成，并在服务端日志中记录该次降级及其原因

#### Scenario: 检索功能被配置为关闭

- **WHEN** 部署配置将检索功能整体关闭
- **THEN** 系统不发起任何外部检索请求，全部按原有流程生成

### Requirement: 检索用量可观测且受每日限额约束

系统 SHALL 记录每次检索的参数与来源网址，并对单用户每日检索次数施加上限。

#### Scenario: 达到每日检索上限

- **WHEN** 某用户当日检索次数已达上限
- **THEN** 后续请求不再发起检索，直接按原有流程生成

#### Scenario: 记录每次检索

- **WHEN** 任意一次检索被实际执行
- **THEN** 服务端日志记录该次检索的来源网址、检索参数与消耗量，且不包含用户隐私内容
